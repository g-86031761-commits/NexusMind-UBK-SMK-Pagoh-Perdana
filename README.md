# NexusMind-UBK-SMK-Pagoh-Perdana
sebuah aplikasi kaunseling interaktif berkonsepkan gamifikasi dan bertema Cyberpunk Neon Yellow. Aplikasi ini dibangunkan khas untuk murid-murid SMK Pagoh Perdana bagi meningkatkan sahsiah diri, mengurus emosi, serta menyediakan saluran komunikasi yang pantas dan selamat bersama Guru Bimbingan dan Kaunseling.
